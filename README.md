# Little Dream World Education Centre 🏫

A modern, fully responsive school website built for **Little Dream World Education Centre** (Kalyanpur, Kanpur). 
The platform provides parents and visitors with comprehensive information about the school, academic programs,
admission procedures, and facilities, featuring an integrated online admission enquiry form.

---

## 🌟 Features

* **Responsive Design:** Optimized seamlessly for mobile phones, tablets, and desktop computers.
* **Interactive Hero & Gallery Sections:** Showcases school infrastructure and student activities smoothly.
* **Online Admission Enquiry:** Clean and user-friendly form layout supporting parent details, student information,
*  class selections, and residential addresses.
* **Interactive Timeline:** Highlights the school's growth and journey over the years.
* **Leadership Profile:** Dedicated section highlighting the vision of the Manager & Principal.
* **SEO & Analytics Ready:** Configured with Google Search Console verification meta tags.

---

## 🛠️ Tech Stack

* **HTML5** – Semantic markup and modern document structure.
* **CSS3** – Custom styling, layout management, and responsive media queries.
* **Bootstrap 5.3.3** – Mobile-first responsive grid system and UI components.
* **JavaScript** – Interactive elements and dynamic content handling.
* **Netlify Forms** – Backend handling for admission enquiry submissions without a traditional server.
